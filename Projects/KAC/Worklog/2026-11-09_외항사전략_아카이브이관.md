# 외항사 전략 아카이브 이관

기록일: 2026-11-09 KST.

## 계기와 처리

사용자가 프로젝트 폴더 안에 기존 Obsidian vault가 있음을 확인하고, 전략 문서를 옮겨 지속 아카이빙하는 방식을 제안했다. `KAC_Project`에 vault 설정과 기본 Welcome 문서만 있어 기존 사용자 노트와 충돌 없이 `10_전략/외항사_유치전략/`를 만들었다.

기존 `전략부분/외항사_유치전략/`의 Markdown 7개를 하위 구조째 이동했다. 원문 보존 영역과 추가 논거는 유지했으며, 참고자료 상대경로와 반영용 문서의 절대경로를 새 위치에 맞췄다. `00_인덱스.md`와 본 변경 기록을 추가하고 이전 위치에 안내문을 남겼다.

## 운영 선택과 범위

- 프로젝트 내부 vault에서 전략·자료 경로·To-do·작업 기록을 관리한다.
- 원본 PPT·DOCX·XLSX·CSV와 기존 분석 결과물은 이동하지 않는다.
- 외부 `00_SDC/WorkVault` 저장 시도는 권한 제한으로 완료되지 않았으며, 현재 전략 아카이브는 프로젝트 vault 방식으로 대체했다. 기존 반영용 문서는 당시 이력으로 보존한다.
- 본 선택은 문서 관리 방식에 관한 것이며, 외항사 유치 대상·전략·지원 예산의 확정을 뜻하지 않는다.
