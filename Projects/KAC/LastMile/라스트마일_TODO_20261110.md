### P3. 검색→예약→결제 서비스 구조

```
일본 지방공항 교통을 검색·예약·결제까지 한 번에 처리하는 플랫폼/앱 구조를 조사해 주세요.

대상 플랫폼 (확인 가능한 것 위주):
- ANA 旅CUBE, JAL MaaS, GO(タクシー配車アプリ), Japan Bus Online, 지역 MaaS(예: わいわいパス, RYDE PASS, 아사쿠루 패스), Kamikuru Pass, 교통 IC카드 연계

각 플랫폼별로 다음을 표로 정리:
1. 취급하는 교통 종류(항공연계 버스, 택시, 렌터카, 관광버스, 페리 등)
2. 검색 → 예약 → 결제가 한 화면에서 끝나는지, 외부 사업자로 넘어가는지
3. 결제 방식(카드, 캐시리스, 교통 IC, 현금)과 결제 주체(플랫폼사 / 운송사 / 공항)
4. 외국인 이용 조건(여권 인증, 해외 카드, 다국어 지원)
5. 공공이 개입한 흔적이 있는지(사업비, 실증 사업, 지자체 협의회 참여)
6. 수수료 구조와 정산 주체가 공개되어 있는지

핵심 질문: "고객이 공항에서 목적지까지 가는 교통편 하나를 예약·결제하기 위해 거치는 단계는 몇 개인가?" 사례 3개 이상에 대해 단계 수를 비교.

출처: 각 플랫폼 공식 사이트, 항공사 보도자료, 지자체 실증 자료.
```

### P5. 렌터카 광역 이동과 주유 루트

```
렌터카를 이용한 광역 관광 이동(여러 지역을 넘나드는 여정)의 실제 사례와 데이터를 조사해 주세요.

확인할 것:
1. 공항 간 편도반납 사례(예: 신치토세 C049, 쇼나이–야마가타·아키타 C23·C24, 아오모리–미사와 C14)에서 실제 이용 데이터(건수, 반납 방향, 이동 거리)가 공개되어 있는지
2. 렌터카 이용자의 평균 이동 거리·방문 지역 수에 대한 공식 조사 (관광청 '주유형 관광' 조사, 렌터카 협회 통계 등)
3. 주유 루트(관광 주유, 드라이브 코스)를 렌터카와 결합한 상품 사례: 주유패스 + 렌터카, 드라이브 코스 + 편도반납 등
4. 렌터카와 대중교통이 보완 관계로 쓰인 사례 (예: 공항 대중교통 + 현지 렌터카)
5. 외국인 렌터카 이용의 장벽 (국제운전면허, 보험, 인수 방법) 중 공공 지원으로 해결된 사례

출처: 관광청 조사, 국토교통성 자료, 렌터카 사업자 보도자료, 지자체 실증 보고서.
```
