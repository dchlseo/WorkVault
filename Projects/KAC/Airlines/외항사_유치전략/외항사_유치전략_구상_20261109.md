# 외항사 유치 전략 구상 — 검토 초안

작성일: 2026-11-09 KST. 기반: [20261106_notes](<20261106_notes.md>), [자료 매핑](<외항사_참고자료_로컬매핑_20261109.md>).  
최종 유치 대상·사업성·기관 합의가 확정된 문서가 아니다. 원본 구상을 전략 작성의 출발점으로 재배열했다.

## 중심 문장

공항별 배후 관광수요와 기존 항공공급을 결합해 우선 검토시장을 도출하고, 외항사가 추가할 수 있는 현지 고객·해외 연결·공급 안정성과 권리·운영자원 활용 가능성을 검증한 뒤, 취항·운항 유지에 필요한 교통·관광·마케팅·정책 협업과제를 제시한다.

## WHY 외항사 — 운수권·슬롯 논거 보완 (2026-11-09 추가)

> **상대국 항공사의 자국 측 운수권과 현지 거점·기존 슬롯을 활용하여, 국적사 중심의 노선 확대를 보완하는 공급 경로를 확보한다.**

- **운수권: 조건부 제도적 보완 경로.** 양국이 각각 지정한 항공사가 협정상 권리를 행사하므로, 한국 측 항공사의 운수권 배분·활용에 제약이 있는 경우 상대국 지정 항공사의 자국 측 권리·미사용 공급 한도는 별도의 검토 경로가 될 수 있다. 실제 여유와 활용 가능성은 해당 양자협정, 부속 노선표, 지정·허가, 국가/노선별 공급 한도 및 최신 배분·사용 현황으로 확인한다. 양국 한도의 일률적 대칭성이나 상대국 측 여유를 가정하지 않는다.
- **슬롯: 국적 우대보다 기존 자원 활용의 이점.** 상대국 항공사가 현지 거점과 기존 슬롯, 기재·승무원 운영 기반을 보유한다면 신규 진입 항공사보다 운항계획 조정에 유리할 가능성이 있다. 이는 항공사별 운영상 가설이며 슬롯의 신규 확보나 기존 슬롯의 한국 노선 전환 가능성이 보장된다는 뜻은 아니다.
- **확인된 일반 원칙.** IATA WASG는 슬롯 배분과 양자협정상 운수권을 별개로 규정하고, 중립·투명·비차별 조정과 기존 사용 실적에 따른 우선권을 제시한다. 따라서 ‘각 국가의 항공사는 자국 슬롯을 쉽게 확보한다’를 일반적 제도 사실로 사용하지 않는다. 현지 법령과 양국 공항의 실제 가용 시간대는 별도 확인한다.
- **전략 적용.** 후보표에 ‘한국 측/상대국 측 운수권·지정·사용 현황’, ‘양국 공항 희망 시간대’, ‘항공사 기존 슬롯·조정 가능성’, ‘운영 기반’, ‘항공사 의향’을 각각 기록한다. 권리·시간대 확보와 노선 사업성·관광 순증 효과도 나누어 검증한다.

## 시장 → 노선 → 항공사 → 실행조건

1. 공항–관광권역 가설: 국적별 방문 특성·동반 방문을 출발점으로 삼고 통신 OD·교통으로 실제 이용 개연성을 검증한다.
2. 후보시장 두 경로: A) 기존 이용이 있는 시장의 외항사 신규 진입·증편·도시 확대, B) 지역 방문수요가 있으나 현재 직항 공급이 작거나 없는 시장의 신규 연결.
3. 도시·공항·항공사 세분: IATA 범위를 확인한 뒤 해외 출발지·경유·항공사 네트워크·기재·판매망을 대조한다.
4. 실행 가능성: 양방향·계절수요, 양국 운수권/허가, 공항 시간대·시설, 경쟁과 항공사 의향을 확인한다.
5. 유치·유지 패키지: 후보 여정에 맞춰 판매·상품·교통·운영 지원을 묶고 비용·주체·지원 종료조건을 명시한다.
6. 우선순위: 즉시 협의 / 조건 보완 후 협의 / 추가 조사로 구분. 누락 정보는 미확인으로 남긴다.

## 대표 사례의 현재 위치

- **대구–대만:** 원문은 외국인 출국 60,989명, 대구·경북의 대만 방문 구성비·특화도를 제시한다. 수치는 원분석 확인 전 잠정 인용이며 출국 실적을 방한 순증 수요로 보지 않는다. 기존 EDA T38/T50/T51로 공급·외항사 운항 이력을 먼저 대조한다. 타이거에어 철수 원인은 원출처 확인 과제다.
- **김해–일본:** 기존 이용 규모만으로 ‘공급 부족’ 또는 ‘외항사 취항 필요’를 도출하지 않는다. 현지 판매·인바운드 추가 기여와 실제 시간대·시설 제약을 구분해 비교한다.
- **광역 연결:** 대구 입국–경주/부산 관광–김해 출국은 인터뷰 기반 여정 사례다. 노선·국적별 규모와 이동 경로를 확인한 뒤 이중 관문 지원 여부를 판단한다.
