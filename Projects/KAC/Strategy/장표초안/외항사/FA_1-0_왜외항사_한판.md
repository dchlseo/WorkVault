# FA 1-0 (F1) | 외항사가 필요한 세 가지 이유 (한 판)

- 원고: 외항사 유치전략 원고 v0.6 p.1-0
- 역할: 외항사 파트의 첫 장. 이유 세 개를 한 판에 보여 주고 1-1~1-3이 하나씩 풀어 감
- 우선순위: 핵심 · 상태: 와꾸 v2 (헤드 원문 반영)

## 헤드메시지 (원고 원문 · 수정 금지)
지방공항의 인바운드를 늘리려면 외항사 유치가 필요하며, 그 이유는 ① 한두 개 국적사에 묶인 공급원을 넓히고 ② 상대국 현지 판매망으로 외국인을 직접 모객하며 ③ 상대국 측 운수권과 거점공항 슬롯을 쓸 수 있기 때문임.

## 소제목 (원고 원문)
외항사가 필요한 세 가지 이유 (한 판)

## 도식
- 패턴: **P01 병렬 근거형** (세 기둥)
- 디자인팩: 89–90 신전(지붕 = 결론, 기둥 3개 = 공급 / 판매 / 제도) 또는 3열 카드에 행 머리
- 선택 이유: 원고 메모 `{세 기둥 — 공급 / 판매 / 제도}`. 세 이유가 대등한 차원(공급, 판매, 제도)이라 P01

## 와이어프레임
```text
+--------------------------------------------------------------------------+
| [헤드] 원고 원문 (위 섹션 그대로)
+--------------------------------------------------------------------------+
|  (지붕 문구 없음 — 헤드가 결론을 담고 있음. 원고에 없는 문구는 넣지 않음)  |
+-------------+---------------------+---------------------+-----------------+
|             | ① 공급원 다변화      | ② 현지 판매망         | ③ 운수권·슬롯     |
| 지방공항의 문제 | 국적사 1~2곳이 공급 대부분, | 국적사는 한국 판매망으로 | 상대국 측 운수권·거점 |
|             | 그 항공사 전략에 흔들림   | 한국인을 주로 모객      | 슬롯은 국적사가 쓰기 어려움 |
| 외항사가     | 다른 나라 항공사가       | 자국 판매망으로         | 자국 측 운수권·슬롯으로 |
| 바꾸는 것    | 공급원으로 더해짐        | 자국민을 모객           | 노선을 엶            |
| 대표 근거    | 대구 최대 항공사 76.4%    | 외항사 = 출국여객 33%,  | 중국은 국가별 배분,    |
|             | 청주 68.8% (LTM)       | 외국인 출국객 약 52%     | 슬롯은 과거 실적 우선  |
|             |      → 1-1           |      → 1-2           |      → 1-3        |
+-------------+---------------------+---------------------+-----------------+
| 출처: D01 T20, D02 s15·s18, P03, W01                               p.  |
+--------------------------------------------------------------------------+
```

## 영역별 내용
- 3열 × 3행 (문제 / 외항사가 바꾸는 것 / 대표 근거). 행 머리는 회색 바
- 대표 근거 숫자만 강조색. 각 열 아래 "→ 1-1/1-2/1-3"

## 데이터·출처
- ① D01 T20 · ② D02 s15·s18 · ③ P03, P01, W01

## 증거 수준
- 근거 수치: [근거] · 세 이유 프레임: [해석]

## 열린 질문
- 시장 현황(국적사의 아웃바운드 편중 등)은 앞 챕터 몫이라 넣지 않음. 앞 챕터에서 그 장표가 실제로 나오는지 확인 필요
- 헤드 원문이 122자로 템플릿 24pt에서 3줄이 될 수 있음. 장표에서는 줄이지 않음 → 원고에서 조정할지 사용자 판단
