# FA 2-0 (F5) | 후보 발굴 프레임워크 (한 판)

- 원고: v0.6 p.2-0
- 역할: [2]장의 틀. 2-1~2-6이 어느 단계를 다루는지 보여 주는 지도
- 우선순위: 핵심 · 상태: 와꾸 v2 (헤드 원문 반영)

## 헤드메시지 (원고 원문 · 수정 금지)
외항사 유치 후보는 국가(시장) → 노선(출발도시) → 항공사 → 공항의 네 단계로 좁히며, 각 단계는 앞 단계에서 남은 후보를 받아 그 단계의 지표로 다시 거름.

## 소제목 (원고 원문)
후보 발굴 프레임워크 (한 판)

## 도식
- 패턴: **P05 프로세스형** (깔때기) + 단계별 표
- 디자인팩: 1 LEVEL 3 (층을 거치며 줄어드는 화살표). 오른쪽에 표 열
- 선택 이유: 원고 메모 `{4단계 깔때기 + 단계별 지표 — 깔때기형}`

## 영역별 내용
- 깔때기 4단, 오른쪽 표 3열 (질문 / 지표 / 결과). '자료' 열은 각주로 내림
- 메모덱이므로 ③에 [보류: 자문 회신 후], ④에 [OD 분석 대기] 상태 라벨 유지
- ①의 '국가 시장 평가'는 앞 챕터 몫임을 작은 글씨로 표시

## 열린 질문 (중요)
- **단계 순서가 실제 스크리닝 순서와 다름.** 프레임워크는 국가 → 노선 순인데, 실제 스크리닝(원고 2-0 두 번째 표)은 롱리스트 97 → 수요 성격 45(노선) → 외항사 기반 43(항공사) → 제도 여건 15/2/2/24(국가) 순이라 국가 기준이 세 번째에 옴. 장표에서 깔때기 숫자를 단계 옆에 붙이면 순서가 꼬여 보임. 대안:
  - (a) 깔때기에는 숫자를 넣지 않고 개념 단계만 표시. 숫자는 F7(2-2~2-4)에서
  - (b) 국가 단계를 '필터'가 아니라 '분류'(시장 유형·제도 구분)로 정의해, 도시 스크리닝과 직교하는 축으로 그림
- 앞 챕터(정혜린 팀장)와 국가 지표를 맞추는 문제는 아직 열려 있음
