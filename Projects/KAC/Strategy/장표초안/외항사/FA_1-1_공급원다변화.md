# FA 1-1 (F2) | 이유 ① 공급원 다변화

- 원고: v0.6 p.1-1
- 역할: 첫째 이유의 근거. 특정 국적사 의존이 공항 전체의 위험이라는 점
- 우선순위: 핵심 · 상태: 와꾸 v1

## 헤드메시지 (장표용)
김해·제주를 뺀 지방공항은 국제선 공급을 국적사 한두 곳에 의존해, 그 항공사가 노선을 줄이면 공항 전체 공급이 함께 줄어듦.

## 소제목
공항별 최대 항공사 점유율과 공급 충격 사례

## 도식
- 패턴: **P08 핵심 차트형** (왼쪽) + **P01** 콜아웃 3개 (오른쪽)
- 디자인팩: 40 BAR (가로 막대) + 109–113의 우측 결론 박스 형식
- 선택 이유: 원고 메모 `{공항별 최대 항공사 점유율 막대 + 공급 충격 사례 3개}`

## 와이어프레임
```text
+--------------------------------------------------------------------------+
| [헤드] 김해·제주를 뺀 지방공항은 국적사 한두 곳에 의존 ... 함께 줄어듦    |
+-----------------------------------+--------------------------------------+
| 최대 항공사 점유율 (LTM, %)        | 공급 충격 사례                        |
|  대구 (트리니티항공) ████████ 76.4 | [대구] 대구–타이베이 2025 20.4만 명(3개사) |
|  청주 (에어로케이)  ███████ 68.8   |        → LTM 11.9만 명(1개사)          |
|  김해              ███ {25~29}    | [청주] 여객은 2019의 3.9배, 외항사 점유율  |
|  제주              ███ {25~29}    |        20.5% → 3.7%                   |
|                                   | [양양] 2023 여객 97%를 맡던 플라이강원   |
|                                   |        기업회생 → 정기 국제선 소멸       |
+-----------------------------------+--------------------------------------+
| 출처: D01 T20·T25, D05, D07 Y2, Q02-대구                           p.  |
+--------------------------------------------------------------------------+
```

## 영역별 내용
- 왼쪽 막대: 대구·청주 강조, 김해·제주 회색 비교군
- 오른쪽 카드 3개: 공항명 라벨 + 전·후 숫자 (화살표)

## 데이터·출처
- D01 T20(집중도), T25(청주), D05 + Q02-대구(대구–타이베이), D07 Y2(양양)

## 증거 수준
- 점유율·여객: [근거] · "국적사 대만편 감편 뒤 대만인 입국 감소"는 공항 측 설명이라 [진술]로 표기

## 열린 질문
- 김해·제주의 정확한 값 필요 (원고에는 "25~29%"만 있음) → D01 T20에서 확인 ⟦확인⟧
- 양양·무안 막대를 넣을지 (양양은 현재 정기 국제선이 없고, 무안은 폐쇄 중)
- 대구–타이베이 감소 차트를 따로 작은 막대로 그릴지, 텍스트로 둘지
