# LM 1-1 | 도착 이후 여정 체인 (문제 정의)

- 원고: 라스트마일 아웃라인 v0.6 p.1-1 (+1-5 성과 단위를 하단 띠로 흡수)
- 역할: 라스트마일 파트 첫 장. 문제를 정의하고, 이후 [2]~[5]가 체인의 어느 고리를 다루는지 보여 주는 로드맵
- 우선순위: 핵심 · 상태: 와꾸 v1 (2026-11-13)

## 헤드메시지 (장표용)
국제선을 유치해도 공항 도착 이후 첫 이동과 지역 체류가 이어지지 않으면 노선 효과가 지역에 닿지 않음.

## 소제목
노선 유치와 도착 이후 이동의 연결

## 도식
- 패턴: **P11 문제 진단형** (주) + P05 프로세스형 (보조)
- 디자인팩: 2–4 FLOW 5 (셰브론 헤더 + 하단 텍스트)
- 선택 이유: 원고 메모 `{도식화: 노선 유치 → 공항 도착 → 첫 이동 → 관광권 이동 → 숙박·소비 → 출국 공항. 어느 한 고리가 끊기면 효과가 지역에 닿지 않음}` 그대로. 여정 단계에서 끊기는 지점을 짚는 정보 관계라 P11

## 와이어프레임 (16:9)
```text
+--------------------------------------------------------------------------+
| [헤드] 국제선을 유치해도 ... 노선 효과가 지역에 닿지 않음                 |
| [소제목] 노선 유치와 도착 이후 이동의 연결                               |
+--------------------------------------------------------------------------+
|  >노선 유치> >공항 도착> >[첫 이동]> >[관광권 이동]> >숙박·소비> >출국 공항> |
|                 \_______ 라스트마일 (강조색 브래킷) _______/              |
|  끊기면 →      "대도시로 바로 빠져나감"   "공항을 여정에서 뺌"            |
+--------------------------------------------------------------------------+
| 이 파트의 구성:  [2] 한국 현황 진단 | [3] 대중교통 해법 | [4] 렌터카 |    |
|                  [5] 여정 단위 설계  (각 박스를 위 체인 구간 아래에 정렬)  |
+--------------------------------------------------------------------------+
| 성과 단위:  직접 성과(교통 이용) → 중간 성과(배후지 방문·체류) → 노선 성과 |
+--------------------------------------------------------------------------+
| 출처: 일본 사례 보고서 1장, 관광청 인터뷰                          p.  |
+--------------------------------------------------------------------------+
```

## 영역별 내용
- 상단 체인: 6단계 셰브론. '첫 이동'·'관광권 이동' 두 칸만 강조색, 나머지는 회색
- 체인 아래 '끊기면' 행: 원고 문장 "여행객은 대도시로 곧바로 빠져나가거나 해당 공항을 여정에서 빼게 되어"를 두 개의 짧은 라벨로
- 중단 로드맵 띠: [2]~[5]를 체인 구간 아래에 배치 ([2] 첫 이동 진단, [3] 첫 이동·관광권, [4] 관광권·광역, [5] 전체)
- 하단 성과 띠 (1-5 흡수): 직접 / 중간 / 노선 성과 3칸. "교통 개선만으로 노선 성과의 인과효과를 산출할 수 없어 분리 추적" 한 줄

## 데이터·출처
- J02 1장 (일본 사례 보고서 문제 정의), Q01 관광청 인터뷰
- 1-5 성과 지표: J02 1.2, R03 09

## 증거 수준
- 체인 구조와 '끊기면' 결과: [해석]
- 성과 단위 분리: [제안]

## 열린 질문
- 1-2·1-3(개별여행객 80.3%, 렌터카 의존)을 이 장 옆에 근거 한 장으로 둘지, 2순위로 뺄지
- 1-4(외항사 유치와 라스트마일 연결)는 외항사 파트와 이어지는 다리 역할을 함. 핵심으로 올릴지 사용자 판단이 필요
- 하단 성과 띠를 넣으면 장표가 복잡해짐. 빼고 1-5를 2순위로 둘 수도 있음
