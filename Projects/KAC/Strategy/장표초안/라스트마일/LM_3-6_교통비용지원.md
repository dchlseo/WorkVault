# LM 3-6 | [C 체류 유도] ⑥ 교통비용 지원 (버스·교통 운임)

- 원고: v0.6 p.3-6
- 역할: C 묶음. '조건을 건 지원'이라는 원리를 처음 보여 주고, [4] 렌터카 지원(4-12)으로 이어짐
- 우선순위: 핵심 · 상태: 와꾸 v2

## 헤드메시지 (원고 원문 · 수정 금지)
일본은 숙박 여부나 특정 국제선 이용 등 지원 자격을 조건으로 교통비를 지원하여, 공항 이용객의 지역 내 체류와 기존 교통수단 이용을 유도함.

## 소제목 (원고 원문)
[C 체류 유도] ⑥ 교통비용 지원 (버스·교통 운임)

## 도식
- 패턴: **P10 사례 카드형** (카드 2개, 행 = 조건 → 지원 → 실적)
- 디자인팩: 76 제목 바 박스 2개 + 하단 화살표(→ [4])
- 선택 이유: 원고 두 사례가 (숙박 조건) (도착편 조건)으로 조건 축이 같음. 카드 행을 '조건 / 지원 / 실적'으로 맞추면 조건이 핵심이라는 메시지가 보임

## 와이어프레임
```text
+--------------------------------------------------------------------------+
| [헤드] 원고 원문 (위 섹션 그대로)
| [소제목] 원고 원문 (위 섹션 그대로)
+------------------------------------+-------------------------------------+
| (숙박 조건) 이바라키                 | (도착편 조건) 도쿠시마                 |
| 조건: 현내 숙박객                    | 조건: 지정 국제선 도착객                |
| 지원: 미토역·이시오카역 → 공항 버스   | 지원: 기존 외국인 버스패스를 무료 제공   |
|       편도 운임 무료                 |  (새 상품 대신 기존 상품을 자격 조건으로 |
| 실적: FY2024 4,798건,               |   활성화)                             |
|       약 511만 엔(교부 기준)          | 실적: 현재 지속 여부·배포량 확인 중      |
+------------------------------------+-------------------------------------+
| 렌터카(자가운전) 지원도 같은 원리로 설계됨 → [4]                            |
+--------------------------------------------------------------------------+
| 출처: J01 C239 · J02 2.3                                          p.  |
+--------------------------------------------------------------------------+
```

## 영역별 내용
- 카드 안 '조건/지원/실적' 라벨은 배치용 구분이고, 문장은 원고 원문을 나눠 담음
- 하단: 원고 마지막 줄 그대로
