## 도식
- 패턴: **P05 프로세스형** (단계 열) × 사례 행 = 레인형 타임라인
- 디자인팩: 73 FLOW WITH 3 COLUMN (셰브론 헤더 × 사례 행)
- 선택 이유: 원고 마지막 줄 "실증 → 실적 확인 → 노선 정리 → 정규화"가 단계 구조. 같은 단계에서 사례가 갈라지는 모습을 보여 주기 좋음

## 와이어프레임
```text
+--------------------------------------------------------------------------+
| [헤드] 원고 원문                                                         |
| [소제목] 원고 원문                                                       |
+--------------------------------------------------------------------------+
|              > 실증 >      > 실적 확인 >    > 노선 정리 >    > 정규화 >    |
| (정착) 아오모리  2023.10 실증  FY24 366명 → FY25 565명  저이용 노선 정리  2026.10 본격 운행 |
| (광역 정액) 사가 리무진택시: 19개 지역 예약형 정액, 전날 16시 예약 (보도)   |
| (조정) 후쿠야마·오노미치  3개월 실증  편당 0.4·0.7명 (목표 2.1·1.7)  → 정시 / 수요응답형 전환 |
| (반례) 도야마 소라택시  2016 시작 ................................ 현재 운휴 |
+--------------------------------------------------------------------------+
| "실증 → 실적 확인 → 노선 정리 → 정규화"의 순서를 밟을 때 지속됨을 시사함   |
+--------------------------------------------------------------------------+
| 출처: J01 C197·C224·C086·C205                                      p.  |
```

## 영역별 내용
- 원고 (정착) (광역 정액) (조정) (반례) 네 항목을 행으로. 라벨도 원고 괄호 표기 그대로
- 사가(광역 정액)는 단계 구조에 맞지 않아 셰브론 밖 한 줄로
- 하단: 원고 결론 문장 그대로
