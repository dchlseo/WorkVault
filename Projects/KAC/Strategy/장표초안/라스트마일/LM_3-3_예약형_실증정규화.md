# LM 3-3 | [A 취항] ② 예약형 교통: 실증 → 정리 → 정규화 (+③ 운행 유지)

- 원고: v0.6 p.3-3 (+3-4 운행 유지·비상 대응을 하단 박스로 흡수)
- 역할: 수요가 얇은 곳의 해법과 '조정하면서 정착'하는 과정. 무안·양양 처방(예약형 우선)의 근거
- 우선순위: 핵심 · 상태: 와꾸 v1

## 헤드메시지 (장표용)
수요가 얇은 배후지에서는 예약형 교통이 대안이 되었으며, 실증 실적에 따라 노선을 정리하거나 방식을 바꾸며 정착함.

## 소제목
예약형 교통의 경로: 정착 · 전환 · 운휴

## 도식
- 패턴: **P05 프로세스형** (단계 열) × 사례 행 = 레인형 타임라인
- 디자인팩: 73 FLOW WITH 3 COLUMN (셰브론 헤더 4개 × 사례 3행)
- 선택 이유: 원고의 해석 "실증 → 실적 확인 → 노선 정리 → 정규화" 자체가 단계 구조. 같은 단계에서 사례가 갈라지는 모습을 보여 주기 좋음

## 영역별 내용
- 사례 3행. 결과 칸에 정착 / 전환 / 반례 라벨
- 사가 공항 리무진택시(19개 지역 예약형 정액)는 '광역 정액형' 보조 사례로 각주 처리 가능
- 하단 박스 (3-4 흡수): 운행 유지·비상 대응 두 줄
