## Evidence conventions
- [Verified / 확인]: evidence was read; qualify what it proves. A draft verifies a proposal exists, not that it was approved.
- [Recollection / 회고]: user account or inherited recollection; identify speaker and original date.
- [Inference / 추정]: AI interpretation with supporting evidence; never silently promote to fact.
- [Needs verification / 확인 필요]: missing, ambiguous, conflicting or stale evidence.
- Distinguish source claims, interview statements, proposals, confirmed decisions, scheduled events and completed actions.
- Each important claim: original link/path + source date + reviewed date. Give page/slide/section when practical.
- Search snippets and file metadata must be identified as such. Filename dates and modified times alone do not prove work completion.
- Numbers require units, population/denominator, period, assumptions and method. Do not manufacture precision.
- If sources conflict, retain both, assess authority and definition, and document why the current interpretation changed.

## Tasks and decisions
Tasks have ID, status, action, owner, due date, source and last review. Use unknown rather than inventing owners/dates.
Keep AI suggestions and old follow-ups separate from confirmed current commitments. Mark done only with evidence.
Decisions need content, date, decision-maker, rationale and source; proposals stay proposals.

## Preserve history
Append journal entries; do not rewrite an earlier entry silently. Add a dated correction with a link.
Before changing a material project/context status, record the prior state, new evidence and reason in today's journal.
Update existing notes, avoid duplicate project summaries, and preserve superseded decisions.
No automatic daily logs, connector refreshes or reminders have been configured. Maintenance occurs when requested in a working session.

## Information boundaries
Desktop access is authorized for reading relevant work context. Never move, delete or modify source work outside WorkVault.
Do not copy credentials, identity/account numbers or unnecessary personal information into notes.
Use company-authorized sources and accounts; do not sync or export corporate material to personal MindVault or personal services.
Do not change sharing permissions, send messages or publish notes as part of memory maintenance.
Company policy takes precedence when available. Policy details not reviewed must remain marked unknown.
Use focused summaries and links instead of bulk email/message/document copies.
